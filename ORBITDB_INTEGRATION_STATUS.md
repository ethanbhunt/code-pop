### 1.4 Database Schema - ALL 8 DATABASES ✅

**Total Databases**: 8 (created by bootstrap-node.js)

1. **users-db** (Key-Value)
   - Stores user accounts with hashed passwords
   - Key format: `user:{userId}`
   - Fields: userId, username, passwordHash, email, firstName, lastName, isStaff, isSuperuser, dateJoined, lastLogin

2. **tokens-db** (Key-Value)
   - Stores authentication tokens
   - Key format: `token:{tokenKey}`
   - Fields: tokenKey, userId, createdAt, expiresAt

3. **preferences-db** (Key-Value)
   - Stores user drink preferences
   - Key format: `preference:{preferenceId}`
   - Fields: preferenceId, userId, preference, createdAt

4. **drinks-db** (Key-Value)
   - Stores drink recipes and menu items
   - Key format: `drink:{drinkId}`
   - Fields: drinkId, name, syrupsUsed, sodaUsed, addIns, rating, price, size, ice, userCreated, favorites, createdAt

5. **inventory-db** (Key-Value)
   - Stores stock levels and supplies
   - Key format: `inventory:{inventoryId}`
   - Fields: inventoryId, itemName, itemType, quantity, thresholdLevel, createdAt

6. **orders-db** (Key-Value)
   - Stores customer orders
   - Key format: `order:{orderId}`
   - Fields: orderId, userId, drinkIds, orderStatus, paymentStatus, pickupTime, creationTime, lockerCombo, stripeId

7. **notifications-db** (Key-Value)
   - Stores system notifications
   - Key format: `notification:{notificationId}`
   - Fields: notificationId, userId, message, type, createdAt, read

8. **revenues-db** (Key-Value)
   - Stores payment and revenue tracking
   - Key format: `revenue:{revenueId}`
   - Fields: revenueId, userId, orderId, amount, paymentMethod, stripePaymentId, createdAt

**Replication**: All databases automatically replicate via gossipsub protocol across all peer nodes.
