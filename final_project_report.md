## Sprint 3 - Development (1)
This was kind of a weird sprint for us, with spring break in the middle and midterms starting when we got back. It would have been good to have had a few more meetings to keep track of progress, but we were all pretty busy trying to get things done. We decided that the main things we wanted to focus on were the databases, the ordering app, and the dashboard app. We still had some problems with running the app consistenly, so that slowed us down. We were able to get a web app set up for the dashboards, the databases are working with OrbitDB for decentrilization, and we got the updated AI drink generation working.
